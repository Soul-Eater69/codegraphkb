##### MOTTO

> Ship small. Ship smart. Let the graph do the thinking.

I build tools that help LLMs reason about code — without drowning them in tokens.
Currently focused on **[CodeGraphKB](https://github.com/Soul-Eater69/codegraphkb)**: a graph-powered context compiler that indexes your repo once, then serves only the context an agent actually needs.
