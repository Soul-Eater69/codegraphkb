### About me

I build tools that help LLMs reason about code — without drowning them in tokens.

Currently working on **[CodeGraphKB](https://github.com/Soul-Eater69/codegraphkb)**: a graph-powered context compiler that indexes your repo once, then serves the smallest useful slice of context to Claude, Cursor, Codex, or any other coding agent.

- Turning codebases into structural graphs (files → functions → calls → routes → tests)
- Building compact **Context Capsules** per symbol, ranked by retrieval intent
- Shipping as a library, CLI, MCP server, and HTTP API
